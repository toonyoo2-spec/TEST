## 4. 원본 미제공 → 확정 대체 방식 적용

| 컷 | 대본 원 지시 | 적용한 대체 |
|---|---|---|
| A06~A09 | 학습 방식 예시 | 앱 밖 예시 카드·연필 획·빈 문장 칸, '학습 방식 예시' 상시 표기. 첨삭 창·점수·말풍선 없음 |
| A08 | "태블릿에서 예시 문장 칸으로 매치컷" | 예시 카드가 앱 UI처럼 보이지 않도록 A06~A07에 태블릿을 두지 않고, 연필 획을 따라 예시 카드 → A01의 문장 칸으로 매치컷 |
| B07 | 앱 구조도의 '커리큘럼' 메뉴 표식 + 수준별 시작 개념 카드 | '커리큘럼' 강조색 표식 + 같은 크기 개념 카드 3장 중 1장 정적 강조. 레벨명·점수·자동 진단 없음 (캡처에 커리큘럼 메뉴 없음) |
| B09 | Figma 태블릿 + 자사 캐릭터 | 캐릭터 사용 권리 미확인 → 집 프레임 + 실제 홈(정제본) 태블릿 + 정적 위치 아이콘 |
| C05 | Figma 마이페이지 아이콘 | 캡처의 마이페이지 아이콘은 계정 아바타/캐릭터일 수 있어 블러. 홈 하단 마이페이지 **위치**에 링 표시 → 일반 문서 도형 '리포트 확인 경로' |
| C06~C10 | 결과 카드 | '라이팅 결과'/'스피킹 결과' 설명용 카드(아이콘+제목만), '결과 확인 예시' 표기. 점수·그래프·실제 데이터 없음 |
| 브랜드 스타일 | 원본 폰트·컬러 | 규정 미제공 → **임시 스타일**: 흰 배경 #FFFFFF, 글자 #15181D, 보조 #565E69, 강조색 1개 #0A8A58 (앱 캡처 초록 계열을 명도만 낮춤), `src/css/style.css` 토큰 |
