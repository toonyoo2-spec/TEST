# 선생님 Q&A 대본 정리 · 1차 보고서

작성일: 2026-10-02
대상 문서: 줄리 선생님 / 애니 선생님 / Q&A 공영규 VER (줄리쌤 전용) / 줄리 Q&A (재호)
결과물: `01_줄리_선생님.md` (1부·2부), `02_애니_선생님.md` (1부·2부 + 1부 대체안), `선생님_전달용/` (선생님별 촬영 안내 PDF)

> **3차 수정 반영 (용어 정리)**
> - 한 선생님의 Q&A 촬영 안에서 **1부(기본) → 2부(솔직 토크) → 쇼츠** 순서로 이어서 진행하는 구조로 바꿨습니다.
> - 줄리쌤: 아래에서 말하는 **A안 = 1부**, **B안 = 2부**
> - 애니쌤: **기본안 = 1부**, **AI 질문 = 2부**. 공부법 팩트체크(원래 대안)는 1부 대체안으로 문서 맨 아래에 보관
> - 선생님 전달용 PDF는 7장에 정리

## 1. 한눈에 보기

- **줄리쌤 문서 3개를 하나로 합침.** 줄리 1편, 공영규 VER, 재호 VER은 결국 같은 질문(초3에 시작해도 늦지 않나 / 뭐부터 하나 / 잘 가고 있나)을 다르게 짠 버전이라, 각 문서에서 가장 강한 문항만 골라 **A안(기본편)**을 만듦
- **줄리쌤 B안(도전편)을 새로 만듦.** “원서 꼭 읽어야 해요?”, “레벨테스트 믿어도 돼요?”, “대치동 방식 따라가야 해요?” 같은 불편한 질문으로 구성. 형식은 A안과 같음
- **AI 질문은 애니쌤 2부로 모음.** 원래 애니쌤 대안의 ‘본질·미래’ 파트에 있던 AI 질문을 AI 번개 O/X와 AI 질문 2개로 확장해 2부로 구성
- **애니쌤은 기본안 구조를 유지하고 다듬음.** 뻔한 O/X를 교체하고, 줄리쌤 쪽과 겹치는 질문을 정리. 대안(팩트체크)은 1부 대체안으로 보관
- **2차 수정: 모든 버전을 촬영 큐시트 형식으로 통일.** 분기 질문, 교체 카드, 쇼츠 질문을 따로 두지 않고 쓰는 시점(STEP) 안에 넣어, 촬영장에서 위에서 아래로 그대로 진행할 수 있게 함 (자세한 내용은 3-4)
- **편 안과 편 사이에 연결 멘트(🔗)를 모두 써 넣음.** 원본은 O/X → 메인 1 연결 하나만 있었음
- **영상 리텐션 장치를 대본에 직접 넣음.** 하이라이트 인트로, 인사 압축, 오픈 루프(끝까지 볼 이유), O/X 본편 6개 노출, 메인마다 🔥 재후킹 질문, 중반 쉼표, 엔드스크린 예고

## 2. 원본 진단

### 2-1. 문서별 특징

| 문서 | 강점 | 아쉬운 점 |
|---|---|---|
| 줄리 1편 | 형식이 가장 완성됨 (★판단 기준 / 사례 / 분기 / ★실천 + 확보할 답변) | 학년이 초1·초2·초3으로 흩어짐. O/X 중 답이 뻔한 문항이 많음 (알파벳, 영어 이름, 정답 개수) |
| 공영규 VER | 페르소나가 선명함 (초3 시작 부모). 아젠다 흐름이 좋음. 🔥 도발 질문 있음 (“솔직히 늦은 편인가요?”). 3,000시간 같은 숫자 | 메인이 5개라 한 편에 담기에 많음. O/X가 대부분 ‘대치동 아이들은~’이라 비슷한 문항이 반복됨 |
| 재호 VER | 타깃이 뾰족함 (대치동에 못 보내는 부모). 오프닝 대본이 완성형. 오픈 루프 멘트 있음 (“다 방법이 있습니다, 끝까지 보시면”). ‘3개월 점검’이라는 결론부 | 메인 3 ‘영어 못하는 학부모’가 애니쌤 메인 1과 거의 같음. 자막·레벨테스트 O/X도 애니쌤과 겹침 |
| 애니 2편 | 주제 흐름이 깔끔하고 꼬리질문 설계가 좋음 | O/X 일부는 답이 너무 뻔함 (“함께 따라 말하면 도움이 된다”, “과정을 칭찬해도 된다”). 대안안은 AI 파트가 짧게 끝남 |

### 2-2. 문서 사이에 겹치는 질문

| 주제 | 겹친 곳 | 정리 |
|---|---|---|
| 부모가 영어를 못해도 되나 | 재호 메인 3·O/X 9, 애니 메인 1·O/X 10 | **애니쌤만 다룸.** 재호 VER의 꼬리질문(“막혔을 때 부모 반응”)은 애니 메인 1로 옮김 |
| 영상 자막 | 재호 O/X 8, 애니 대안 메인 1·O/X 10, 애니 심화 | **애니 기본안 O/X 2번**으로 모음 |
| 레벨테스트 | 재호 O/X 6, 애니 심화 | **줄리 B안 메인 2**로 모음. 줄리 A안에서는 교체 카드로 뺌 |
| 단어 암기 | 공영규 O/X 8·Q4, 애니 메인 3 | 역할 나눔: 줄리 = **무엇부터**(순서), 애니 = **어떻게**(잊지 않게). 줄리 메인 2에서 “어떻게 외우는지는 2편에서”로 넘김 |
| 문법 시작 시기 | 줄리 1편 메인 3, 공영규 Q4, 1편 예비 O/X | 줄리 A안 메인 2의 꼬리질문 1개로 줄이고, 원래 메인 3 세트는 **교체용 완성 세트**로 보관 |
| AI 시대 영어 | 애니 대안 본질·미래 | **애니쌤 대안이 맡음.** 줄리쌤 쪽에는 AI 질문을 넣지 않음 |
| 대치동 격차 | 공영규 Q1·Q2·Q5, 재호 메인 1·4 | 줄리 A안 메인 1(격차의 실체)과 메인 3(따라 하지 않아도 되는 것)에 나눠 배치 |

### 2-3. 영상으로 볼 때의 구조 문제

1. **인트로가 김.** 시청자가 무엇을 얻는지 말하기 전에 자기소개가 길어서, 이탈이 가장 많이 생기는 구간에 정보가 없음
2. **O/X 10개를 연달아 진행.** 같은 형식이 길게 반복되고, 답이 뻔한 문항은 긴장감이 없음
3. **연결 멘트가 O/X → 메인 1 하나뿐.** 메인 1 → 2 → 3, 속마음 → 마무리로 넘어갈 때 화제가 뚝 끊김
4. **끝까지 볼 이유가 없음.** 재호 VER의 “끝까지 보시면”을 빼면 결말을 약속하는 장치가 없음
5. **편과 편 사이 연결이 없음.** 1편이 끝나고 2편으로 넘어가는 장치가 없음

## 3. 반영 내용 상세

### 3-1. 줄리쌤 A안 · 초3 영어, 지금 시작해도 늦지 않았을까요?

**페르소나와 축**
- 공영규·재호 VER의 페르소나를 기준으로 통일: “초3에 영어를 처음 시작하는, 대치동에 보내기 어려운 부모”
- 1편의 초1(파닉스)·초2(영유) 질문은 초3 상황으로 바꾸거나 예비로 뺌

**구간별 출처와 변경 이유**

| 구간 | 출처 | 바꾼 점 | 이유 |
|---|---|---|---|
| 0. 하이라이트 인트로 | 신규 | 본편에서 가장 단호한 답변 한두 문장을 맨 앞에 배치 | 시작하자마자 “이 영상이 무슨 질문에 답하는지” 보여줘야 함 |
| 1. 인사 | 재호 VER 오프닝 + 1편 소개 카드 | 인사를 짧게 줄이고 경력은 자막으로. 사전 질문 3개를 그대로 영상의 목차로 씀 | 인트로 이탈 줄이기 + 목차로 기대 만들기 |
| 1. 오늘의 약속 | 재호 “끝까지 보시면” | “첫 3개월 체크 신호를 드리겠다”로 **구체화**하고 메인 3에서 회수 | 막연한 약속보다 받을 것이 분명한 약속이 끝까지 보게 만듦 |
| 2. O/X | 세 문서에서 골라 10개 | 답이 뻔한 문항(알파벳, 영어 이름, 정답 개수, 나이별 교재)을 빼고 의견이 갈리는 문항으로 채움. 의외의 문항을 1번에, 불안을 건드리는 문항을 10번에 둠. ⭐ 6개만 본편에 쓰고 나머지는 쇼츠 | 뻔한 답은 넘기게 되고, 의외의 답은 보게 됨. 10번 → 메인 1 연결 구조는 유지 |
| 3. 메인 1 | 1편 메인 1 + 공영규 Q1·Q2 | 질문을 “초3 / 한 번도 안 해봄 / 대치동은 벌써 원서”로 구체화. 공영규의 🔥 “솔직히 늦은 편인가요?”를 꼬리로 넣음 (3,000시간 질문은 확인되지 않은 수치라 삭제) | 질문 하나에 불안(늦음)과 비교(대치동)를 같이 담아 가장 센 질문을 맨 앞에 둠 |
| 4. 메인 2 | 1편 메인 2·3 + 공영규 Q4 + 재호 메인 1 | 파닉스, 단어, 원서, 문법, 학원 고민을 메인 하나로 묶고 꼬리질문으로 나눔. 🔥 “학원 없이 vs 동네 학원” 추가. 10분 시연을 롤플레이로 | 원본에서 메인 2개 이상을 차지하던 ‘순서’ 주제를 하나로 줄여 한 편 분량에 맞춤 |
| 5. 속마음 | 1편 속마음 | **메인 2와 메인 3 사이로 옮김** | 정보가 가장 몰린 뒤 한 번 쉬어가고, 답변(“재미있어하는 순간”)이 메인 3(“잘 가고 있다는 신호”)과 자연스럽게 이어짐 |
| 6. 메인 3 | 재호 메인 4 + 공영규 Q3·Q5 | 3개월·6개월 신호, 하루 학습량, 따라 하지 않아도 되는 것 / 꼭 지킬 것. 체크리스트 카드로 오픈 루프 회수 | 영상의 결말 = 부모가 바로 가져갈 수 있는 것 |
| 7. 마무리 | 재호 마무리 + 공영규 마무리 | 한 문장 + 2편 예고(엔드스크린) | 다음 편으로 시청이 이어지게 함 |
| 예비 | 1편 예비 + 공영규·재호에서 남은 문항 | 문법 시작 기준 세트를 교체용으로 보관. 성향·학원 고르는 법 질문은 쇼츠로 | 버리지 않고 쇼츠 재료로 씀 |

### 3-2. 줄리쌤 B안 · 대치동 OO년차 강사에게 불편한 질문

**설계 의도**
- 부모가 속으로는 궁금하지만 학원 선생님에게 대놓고 묻기 어려운 질문을 진행자가 대신 물음
- A안이 안심시키는 편이라면, B안은 클릭과 댓글을 부르는 편. 제목과 썸네일 자체가 후킹이 됨
- AI 질문은 애니쌤 담당이므로 B안에서는 뺌. 대신 “원서 꼭 읽어야 하나”를 시험·문제집과 비교하는 질문으로 바꿈

**구성**

| STEP | 내용 | 비고 |
|---|---|---|
| O/X 10개 | 타고남·원서·문제집 → 레벨테스트·학원 레벨 → 영유·숙제량 → 학원 탓 → 원서 못 읽으면 소질 없다(메인 1 연결) | O/X 두 가지로만 답함 |
| 메인 1 | 원서, 꼭 읽어야 하나요? (문제집과 비교) | 🔥 “원서를 끝까지 못 읽는 아이가 대부분인데 의미가 있나요?” |
| 메인 2 | 레벨테스트, 믿어도 되나요? | 🔥 “학원이 레벨을 일부러 낮게·높게 주기도 하지 않나요?” |
| 번개 O/X | 선행·문법 2문항 | 메인 3으로 넘어가는 다리 |
| 메인 3 | 대치동 방식, 따라가야 하나요? (영유·선행·문법·숙제량) | 🔥 “대치동 학원이 불안을 파는 측면도 있지 않나요?” → 상담 질문 카드 |
| 속마음 | 역질문 “선생님이 학부모라면 대치동 학원에 보내시겠어요?” | 감정 클라이맥스 |
| 마무리 | 대치동 방식에서 딱 하나만 가져간다면? | |

**운영 리스크와 대응**
- 강사가 방어적으로 답하거나 학원 홍보처럼 들리면 신뢰가 떨어짐 → 🔥 질문은 촬영 전에 반드시 공유하고, 답변 순서를 “인정 → 경계 → 대안”으로 안내
- 진행자는 “제 생각이 아니라 부모님들이 실제로 보내주신 질문”으로 프레이밍

### 3-3. 애니쌤 기본안 · 집에서는 어떻게 도와줄까요?

| 구간 | 바꾼 점 | 이유 |
|---|---|---|
| 하이라이트 인트로·인사 | 하이라이트 인트로 추가, 인사 압축, **1편 연결 멘트** 추가, 오픈 루프 “오늘 저녁 10분 루틴” | 시리즈로 이어 보게 하기 + 끝까지 볼 이유 만들기 |
| O/X | 답이 뻔한 2개(함께 따라 말하기, 과정 칭찬)를 예비로 빼고 “자막 없이”, “단어 많이 외울수록” 넣음. 의외의 문항 “5분만 할 거면 안 하는 게 낫다”를 1번으로 | 긴장감 + 메인 3과 연결 |
| 메인 1 | 재호 VER의 “막혔을 때 부모 반응” 꼬리 이동. 🔥 “부모가 영어를 못하면 한계가 오지 않나요?” 추가 | 줄리 쪽 중복 제거 + 중반 재후킹 |
| 메인 2 | 🔥 “그냥 영상으로만 가도 되지 않나요?” 추가. 10분 루틴 3단 카드 | 오픈 루프 회수 지점 |
| 번개 O/X (신규) | 메인 2와 3 사이에 예비 O/X 2개를 넣어 템포 전환. 마지막 문항으로 단어 주제 연결 | 애니쌤 편은 속마음 질문이 부모 이야기여서 마무리 직전이 더 잘 맞음 → 중반 쉼표는 번개 O/X로 대신함 |
| 메인 3 | 🔥 “단어 시험 자체가 의미 없다는 건가요?” 추가 | 반론으로 긴장 만들기 |
| 속마음 → 마무리 | 원래 순서 유지 + 연결 멘트 추가 | 감정선을 올린 뒤 한 문장으로 마무리 |
| 엔드스크린 | 1편으로 역방향 연결 | 2편을 먼저 본 시청자를 1편으로 보냄 |

**애니쌤 2부 (AI 시대, 영어 공부 솔직 토크)**
- 원래 대안의 ‘본질·미래(AI)’ 파트를 2부로 독립시키고 확장: AI 번개 O/X 3개 → AI 질문 2개 → 한 문장
  - AI 질문 1: “AI가 번역도 요약도 다 해주는데, 원서 같은 걸 굳이 읽어야 하나요?”
  - AI 질문 2: “아이가 숙제를 ChatGPT로 해오고, AI랑 영어로 대화도 해요. 막아야 할까요?”
- 원래 대안(공부법 팩트체크: 자막·단어·일기)은 1부 대체안으로 문서 맨 아래에 보관

### 3-4. 2차 수정 · 촬영 큐시트 형식으로 통일

줄리쌤·애니쌤 문서를 모두 같은 형식으로 맞췄습니다. 3차 수정에서 1부 → 2부 → 쇼츠가 STEP 번호로 이어지도록 했습니다 (줄리 STEP 0~16, 애니 STEP 0~13).

- **STEP 순서 = 촬영 순서**: STEP 0 워밍업(녹화 전) → 인사 → O/X → 메인 → 쉬어가기 → 메인 → 속마음 → 마무리 → 쇼츠 추가 촬영
- **떨어져 있던 블록을 쓰는 자리로 옮김**
  - 현장 워밍업 → STEP 0
  - 예비 O/X → 해당 O/X STEP 안의 🔁 교체 카드 또는 번개 O/X
  - 메인 교체 세트(문법 시작 기준) → 메인 2 STEP 안의 🔁 교체 카드
  - 추가 심화 질문 → 마지막 STEP ‘쇼츠 추가 촬영’
  - 편집 관련 메모 → 각 버전 맨 끝 ‘편집 메모’ (촬영장에서는 안 봐도 되게)
- **꼬리질문 순서 고정**: ① ★판단 기준 → ② 답변 따라 고르기 → ③ 🔥 한 번 더 → ④ ★실천 방법. 진행자가 어느 버전을 들고 가도 같은 리듬으로 질문할 수 있음
- **말하는 사람 표시**: [강사] / [진행]
- **STEP마다 ☑️ 확보 체크와 🔗 다음으로 멘트**: 다음 STEP으로 넘어가도 되는지 현장에서 바로 판단

## 4. 연결성 설계

### 4-1. 편 안의 연결

- **O/X → 메인 연결 태그**: O/X 문항마다 “→ 메인 n”을 달아, O/X에서 생긴 궁금증이 메인에서 풀리도록 함
- **모든 구간 사이에 🔗 연결 멘트를 씀**: 강사·진행자가 그대로 읽을 수 있는 문장
- **화제의 흐름이 질문의 흐름이 되도록 배치**
  - 줄리 A: 늦었나? → (아니라면) 그럼 뭐부터? → (재미있어하는 순간 = 신호) → 잘 가고 있나?
  - 애니: 부모가 도와줄 수 있나? → 아이가 안 따라오면? → (반복은 괜찮은데) 단어는 왜 잊나? → 부모에게 한마디

### 4-2. 편 사이의 연결

| 연결 지점 | 장치 |
|---|---|
| 줄리 A 메인 2 | “어떻게 외우는지는 2편 애니쌤 편에서” |
| 줄리 A 마무리 | 2편 예고 멘트 + 엔드스크린 |
| 애니 인사 | “지난 편 줄리쌤이 ‘언제·무엇부터’였다면, 오늘은 그다음” |
| 애니 마무리 | 1편으로 보내는 엔드스크린 |
| 1부 → 2부 | 1부 마무리 뒤 ‘2부 여는 멘트’로 톤 전환. 2부를 따로 편집할 수 있게 강사 한 줄 소개를 한 번 더 받음 |

## 5. 리텐션 분석 · 이탈, 후킹, 집중력

### 5-1. 예상 이탈 구간과 대응

| 구간 | 이탈 위험 | 원인 | 대응 (대본 반영 위치) |
|---|---|---|---|
| 영상 시작부 | 🔴 가장 높음 | 자기소개부터 시작, 얻을 게 안 보임 | 하이라이트 인트로 → 인사 압축 → 오픈 루프 약속 (STEP 1 인사) |
| O/X 중반 | 🟠 중간 | 같은 형식 반복, 뻔한 정답 | 뻔한 문항 교체, 본편 6개만, 판정 스탬프·효과음, 문항마다 짧게 컷 (STEP 2 O/X) |
| O/X → 메인 전환 | 🟠 중간 | 빠른 퀴즈에서 긴 토크로 템포가 급변 | 부모 사연 카드(채팅 UI·목소리) + 연결 멘트 (메인 1 사연 카드) |
| 메인 2 중반 | 🔴 높음 (중반 처짐) | 정보는 많은데 새로움이 줄어듦 | 🔥 재후킹 꼬리질문, 순서 도식 그래픽, 롤플레이 시연 (메인 2) |
| 메인 2 → 메인 3 | 🟠 중간 | 피로 누적 | 줄리: 속마음 쉼표 / 애니: 번개 O/X (메인 2와 3 사이 STEP) |
| 결론 직후 | 🔴 높음 (자연 이탈) | 답을 들었으니 나감 | 한 문장 → 짧은 여백 → 엔드스크린 다음 편 (마무리 STEP) |

### 5-2. 후킹 설계

1. **하이라이트 인트로**: 본편에서 가장 단호하거나 의외인 답변 한두 문장. 썸네일 문구와 같은 질문이어야 함
2. **제목·썸네일 = 첫 질문**: A안 “초3 시작, 늦었나요?”, B안 “원서 꼭 읽어야 해요?”, 애니 2부 “AI가 다 해주는데?”. 클릭한 이유가 시작하자마자 바로 나옴
3. **오픈 루프**: 인트로에서 결말을 약속하고(줄리 A: 3개월 체크리스트 / 줄리 B: 상담 때 물어볼 질문 / 애니 기본: 10분 루틴 / 애니 2부: 집에서의 AI 사용 규칙) 후반에 카드로 회수
4. **숫자와 고유명사**: 경력 연차(LX팀 확정 후), 3개월·6개월, 10분. 자막으로 크게 보여줌
5. **의외성 O/X를 1번에**: “국어 잘하면 영어도 빨리 는다”, “5분 할 거면 안 하는 게 낫다”처럼 시청자가 자기 답을 맞혀보고 싶어지는 문항

### 5-3. 처지는 구간에 넣을 포인트

| 장치 | 효과 | 위치 |
|---|---|---|
| 🔥 재후킹 꼬리질문 | “솔직히~”, “인정할 건 인정해 주세요”식 반론으로 긴장 만들기 | 메인마다 1개 (영상 중반에 집중) |
| 롤플레이 시연 | 강사가 부모 역할로 실제 대사를 함 → 말하는 장면에서 보여주는 장면으로 전환 | 줄리 메인 2, 애니 메인 1·2 |
| 그래픽 카드 | 순서 도식, 체크리스트, 규칙 카드. 저장하고 캡처할 이유가 됨 | 메인 1·2·3 결론부 |
| 사연 카드 | 채팅 UI·부모 목소리로 질문 제시. 시청자가 “내 얘기”로 느낌 | 메인 질문 제시 시점 |
| 톤 전환 | 속마음 클로즈업, 분위기 전환 | 줄리 STEP 5, 애니 STEP 7 |
| 번개 O/X | 2~3문항을 빠르게. 템포 리셋 + 다음 메인으로 연결 | 줄리 STEP 12, 애니 STEP 5·9 |
| 챕터 타임스탬프 | 원하는 질문으로 이동하게 해서 이탈 대신 건너뛰기를 유도 | 업로드 설명란 |

### 5-4. 업로드 후 확인할 지표

- 도입부 유지율 (하이라이트 인트로·인사 효과)
- O/X가 끝나는 지점의 유지율 그래프 기울기 (O/X 길이가 적절한지)
- 메인 2 중반의 하락 폭 (🔥 재후킹 효과)
- 엔드스크린 클릭률 (편 사이 연결 효과)
- 쇼츠 → 본편 유입 (O/X·실천 카드 쇼츠 효과)

## 6. 결정이 필요한 사항

1. **1부·2부를 한 번의 Q&A 촬영(1시간)에 모두 담을지**: 현재 큐시트와 선생님 PDF는 1부 → 2부 → 쇼츠를 이어서 진행하는 것으로 만들었습니다. 시간이 부족하면 2부나 쇼츠를 줄이는 쪽으로 조정
2. **애니쌤 1부를 기본안(집에서 어떻게)으로 갈지, 대체안(공부법 팩트체크)으로 갈지**: 현재는 기본안 기준
3. **시리즈 페르소나를 ‘초3 시작 부모’로 통일할지**: 애니 메인 2(초2)·메인 3(초4)은 원본 학년을 유지했습니다. 통일하려면 초3으로 바꾸면 됩니다
4. **확인할 사실관계**
   - 선생님 경력·소속: LX팀에서 정리 (큐시트에는 OO로 비워둠)
   - 애니쌤 경력 연차, 주로 가르치는 학년
5. **2부 🔥 질문의 수위**: 강사와 사전 협의 후 확정

### 4차 수정 (줄리쌤 기준)

- ‘촬영 전 체크’ 삭제, 확인되지 않은 정보 삭제(경력 연차·소속은 OO, 3,000시간 질문 삭제)
- O/X는 O와 X 두 가지로만 답함 (△ 삭제)
- 진행자 목소리는 편집에서 빠지므로, 화면에 나오는 말과 연결 멘트는 모두 선생님 멘트([강사])로 바꿈. 질문은 [제작진]이 묻고, 선생님이 질문을 읽거나 되짚은 뒤 답함(📝 질문 자막)
- 연결 멘트는 선생님 답을 미리 가정하지 않는 문장으로 수정
- 인사 → O/X 전환을 자연스럽게 수정 (“그 전에, 주변에서 많이 듣는 말들을 O인지 X인지 짚어볼게요”)
- 선생님 전달용 PDF에도 같은 내용 반영 (△ 삭제, 경력 문구 삭제, ‘영상에는 선생님만 나와요’ 안내 추가)
