## 기본안 · 집에서는 어떻게 도와줄까요?

제목 가안: 영어 못하는 엄마·아빠도 할 수 있다! 집에서 아이 영어 도와주는 법
주제 흐름: 집에서 흔히 하는 행동 → 부모의 역할과 부담 → 책 읽기 갈등 → 단어 학습과 실제 사용

### 0. 하이라이트 인트로 · 약 10초

- 🎬 1순위: 메인 1 🔥 “솔직히 부모가 영어를 못하면 한계가 있는 거 아닌가요?”에 대한 답의 첫 문장
- 2순위: O/X 1번 “5분만 할 거라면 안 하는 게 낫다” 판정 장면

### 1. 인사·강사 소개 · 약 25초

소개 카드 순서: 인사·경력 → 1편 연결 → 오늘의 고민 → 오늘의 약속 → O/X 진입

- 인사·경력: “안녕하세요, 리얼아카데미에서 영어를 가르치고 있는 애니입니다. ○년째 ○학년 아이들을 가르치면서, 집에서는 어떻게 해야 하는지 부모님 상담도 많이 하고 있어요.”
- 1편 연결: “지난 편에서 줄리 선생님이 ‘언제, 무엇부터’를 이야기해 주셨다면, 오늘은 그다음 질문이에요.”
- 오늘의 고민: “상담에서 제일 많이 듣는 말이 ‘그래서 집에서는 뭘 해줘야 하나요?’거든요.”
- 오늘의 약속: “끝까지 보시면 오늘 저녁 10분, 그대로 따라 하실 수 있게 정리해 드릴게요.”
- O/X 진입: “먼저 가볍게 O/X부터 해볼게요.”

사전 확인: 경력 연차·주로 가르치는 학년·수업 특징 (○ 부분 채우기, 자막용 한 줄 경력 문구 포함)
🎬 경력은 자막 카드로 처리 (인트로 40초 → 25초)

### 2. O/X 퀴즈 · 10개 촬영 / 본편 6개 노출

촬영: 강사가 문장을 읽고 O/X/△ + 한 줄 이유로 답변, 짧게 다음 카드로 이동
🎬 판정 스탬프 + 효과음, 문항당 10~15초

1. ⭐ 5분만 할 거라면 안 하는 게 낫다. — 의외성 오프너
2. ⭐ 영어 영상은 자막 없이 봐야 효과가 있다. — 대안에서 이동
3. 영어 영상은 매번 새로운 걸 봐야 효과가 있다. — 쇼츠
4. 집에서 영어를 할 때는 정해진 시간에 시작하는 게 좋다. — 쇼츠
5. ⭐ 영어책을 읽을 때는 한국말을 쓰면 안 된다. → 메인 2
6. 모르는 단어가 나올 때마다 사전을 찾아야 한다. → 메인 3 / 쇼츠
7. ⭐ 단어는 하루에 많이 외울수록 좋다. → 메인 3 (예비에서 이동)
8. ⭐ 숙제에서 막히면 정답을 바로 알려줘도 된다. → 메인 1
9. 학습지만 꾸준히 해도 충분하다. — 쇼츠
10. ⭐ 부모의 발음이 좋아야 집에서 영어를 도와줄 수 있다. → 메인 1 연결 문항

🔗 O/X → 메인 1: “집에서 해볼 수 있는 건 많은데, 막상 도와주려면 부모가 영어를 잘해야 할 것 같다는 부담이 제일 크시더라고요. 이런 질문이 왔어요.”

### 3. 메인 질문 1 · 부모의 영어 실력과 역할 · 약 1분 45초

🎬 질문은 부모 사연 카드(채팅 화면 UI 또는 부모 목소리 내레이션)로 제시

> “제 영어 발음이 좋지 않은데, 집에서 아이를 도와줘도 괜찮을까요?”

꼬리질문 · 답변에 맞춰 2~3개 선택
- ★ 판단 기준: “부모의 영어 실력보다 먼저 필요한 역할이 있다면 무엇인가요?”
- 실제 사례: “영어에 자신 없던 부모님이 아이를 잘 도왔던 경험이 있다면, 구체적으로 무엇을 하셨나요?”
- 분기 · ‘함께하기’가 나오면: “함께할 때 부모가 실제로 어떤 말을 해주면 좋을까요?”
- 분기 · ‘음원 활용’이 나오면: “음원을 틀어주는 것에서 끝나지 않으려면 무엇을 더 해볼까요?”
- 막힐 때: “아이가 혼자 하다 막혔을 때, 부모는 어떻게 반응해야 하나요?” (1편 재호 ver에서 이동)
- 🔥 재후킹: “솔직히, 부모가 영어를 못하면 어느 순간 한계가 오는 거 아닌가요? 그 시점은 언제인가요?”
- ★ 실천 방법: “영어로 설명하기 어려운 부모도 오늘 바로 할 수 있는 행동 한 가지를 알려주세요.”

확보할 답변: 부모가 맡을 역할 + 막혔을 때 반응법 + 부담 없이 시작할 행동
🎬 “부모가 실제로 할 말”은 강사가 대사로 시연 → 자막 카드로 정리

🔗 메인 1 → 메인 2: “부모 역할을 알아도, 막상 아이가 안 따라오면 소용없잖아요. 이 사연이 딱 그 상황이에요.”

### 4. 메인 질문 2 · 책 읽기를 싫어하는 아이 · 약 1분 45초

> “초2 아이가 영어책만 펴면 도망가요. 어떻게 시작해야 할까요?”

꼬리질문 · 답변에 맞춰 2~3개 선택
- ★ 판단 기준: “책이 어려운 건지, 흥미가 없는 건지, 공부처럼 느끼는 건지 어떻게 구분할 수 있나요?”
- 실제 사례: “책을 싫어하던 아이가 관심을 갖게 된 경험이 있다면, 어떤 계기였나요?”
- 분기 · ‘책 선택’이 나오면: “글 수준과 아이의 관심이 다를 때는 무엇을 먼저 맞춰야 할까요?”
- 분기 · ‘강요하지 않기’가 나오면: “그렇다면 부모는 어디까지 권하고 언제 멈추면 좋을까요?”
- 🔥 재후킹: “그렇게까지 싫어하면, 그냥 책은 접고 영상으로만 가도 되지 않나요?”
- ★ 실천 방법: “오늘 저녁 10분 동안 함께 읽는다면, 시작할 때와 끝낼 때 어떻게 해보면 좋을까요?”

확보할 답변: 거부 원인을 구분하는 법 + 실제 10분 읽기 루틴 (인트로 약속 회수)
🎬 “10분 루틴”을 시작/중간/끝 3단 카드로 정리 (쇼츠 1순위)

### 5. 번개 O/X · 리셋 · 약 20초

- 🎬 메인 2와 메인 3 사이에 예비 O/X 2개를 빠르게 넣어 템포 전환
- 추천: “아이가 고른 책을 여러 번 읽어도 괜찮다.” / “영어책을 읽으며 그림만 이야기하는 날이 있어도 괜찮다.”
- 마지막 문항 뒤 🔗 “책은 반복이 괜찮은데, 단어는 반복해도 자꾸 잊어버린다는 고민이 많았어요.”

### 6. 메인 질문 3 · 외운 단어를 금방 잊는 아이 · 약 1분 45초

> “초4 아이가 단어 시험은 매일 보는데 금방 잊어버려요. 하루에 더 많이 외워야 할까요?”

꼬리질문 · 답변에 맞춰 2~3개 선택
- ★ 판단 기준: “시험 점수 외에, 아이가 단어를 알고 있다는 걸 무엇으로 확인하시나요?”
- 실제 사례: “시험은 잘 보는데 말이나 글에서 단어를 못 쓰던 아이에게는 어떻게 접근하셨나요?”
- 분기 · ‘문장 속에서’가 나오면: “문장을 스스로 만들기 어려운 아이는 어떤 활동부터 해볼 수 있나요?”
- 분기 · ‘반복’이 나오면: “계속 시험을 보는 것과 다시 만나는 경험은 어떻게 다른가요?”
- 🔥 재후킹: “그래도 학원은 단어 시험을 보잖아요. 단어 시험 자체가 의미 없다는 건가요?”
- ★ 실천 방법: “오늘 배운 단어 몇 개를 집에서 다시 써보는 장면을 하나 보여주신다면요?”

확보할 답변: 암기량 판단 기준 + 단어를 실제로 쓰게 하는 방법

예비 O/X · 교체·쇼츠·번개 O/X용

- 공부를 끝낸 뒤 “오늘 뭐가 재미있었어?”라고 물어보면 도움이 된다.
- 부모가 아이와 함께 영어를 따라 말하면 도움이 된다. (본편에서 이동)
- 정답보다 도전한 과정을 먼저 칭찬해도 된다. (본편에서 이동)

추가 심화 질문 · 메인 교체 / 별도 촬영

- 피드백: “영어 일기의 틀린 표현은 바로 고쳐줘야 할까요?” / “숙제는 다 했는데 배운 내용을 설명하지 못하면 어떻게 확인해야 할까요?”
- 새로운 고민: “형제의 영어 수준이 다르면 집에서 따로 도와줘야 할까요?” / “아이가 영어로 말하다 실수할까 봐 망설이면 부모가 어떻게 반응하면 좋을까요?”

공통 꼬리질문: “먼저 무엇을 확인해야 할까요?” → “비슷한 상황에서 도움이 됐던 경험이 있나요?” → “잘 안됐을 때는 무엇을 바꿨나요?” → “오늘 집에서 해볼 방법 한 가지는요?”

## 대안 · 공부법 팩트체크 (보류)

📌 상태: 기본안 추천. 이 안을 고르면 아래 조정이 필요함
- 3. 본질·미래(AI) 파트는 줄리 B안 메인 1·2와 겹침 → 줄리 B안을 쓰면 이 파트는 빼기
- O/X 9번(AI 대화), 10번(자막)은 각각 줄리 B안 O/X 3번, 애니 기본안 O/X 2번과 겹침 → 교체 필요
- 이 안을 고르면 상단 콘셉트 표·제목 가안 수정 필요

기획 의도: 학부모가 접하는 영어 공부법을 강사의 경험과 판단 기준으로 점검하는 토크형 구성
진행 흐름: O/X 10개 → 메인 3개와 꼬리질문 → 본질·미래 → 한 문장 마무리
분량: 본질·미래 파트가 추가되므로 메인 질문을 약 1분 30초로 줄이거나 편당 8분대로 조정

### 0. 인사·강사 소개

기본안과 같은 순서. 오늘의 고민만 “부모님들이 많이 들어본 영어 공부법, 정말 맞는지 하나씩 확인해볼게요.”로 교체

### 1. O/X 퀴즈 · 10개

1. 모르는 단어가 나오면 매번 사전을 찾아야 한다.
2. 영어로 말할 때 틀린 표현은 바로 고쳐줘야 한다.
3. 영어책은 소리 내어 읽어야만 도움이 된다.
4. 한 권을 완벽하게 이해해야 다음 책으로 넘어갈 수 있다.
5. 같은 영어책을 여러 번 읽어도 괜찮다.
6. 매일 짧게 공부하는 것보다 주말에 몰아서 하는 게 낫다.
7. 듣기를 잘하면 말하기는 저절로 된다.
8. 영어 학습 앱은 오래 쓸수록 효과가 크다.
9. AI와 영어로 대화하면 다른 말하기 연습은 필요 없다. (줄리 B안과 중복)
10. 영어 영상은 자막 없이 봐야 실력이 는다. → 메인 1 연결 (애니 기본안과 중복)

### 2. 메인 질문 3개

메인 1 · 영어 영상과 자막
> “영어 영상은 자막 없이 봐야 실력이 늘까요?”
- ★ 판단 기준: “아이의 수준이나 보는 목적에 따라 자막 선택이 달라질까요?”
- 실제 사례: “영상은 잘 보는데 말로 이어지지 않았던 아이에게는 어떻게 접근하셨나요?”
- 분기 · ‘이해’가 중요하다면: “아이가 내용을 이해하는지는 무엇으로 확인하나요?”
- 분기 · ‘반복’이 중요하다면: “같은 영상을 다시 볼 때 어떤 활동을 더하면 좋을까요?”
- ★ 실천 방법: “오늘 영상 하나를 함께 본다면, 보기 전과 본 뒤 무엇을 해볼까요?”

메인 2 · 단어 암기와 실제 사용
> “단어 시험은 늘 100점인데, 말하거나 글을 쓸 때는 못 써요. 외우는 것만으로는 부족한가요?”
- ★ 판단 기준: “외운 단어와 쓸 수 있는 단어는 어떻게 구분하시나요?”
- 실제 사례: “단어 시험 점수는 높은데 표현하기 어려웠던 아이에게 어떤 활동을 해보셨나요?”
- 분기 · ‘문맥’이 나오면: “부모가 예문을 직접 만들지 못해도 도울 수 있을까요?”
- 반대 상황: “암기 자체가 먼저 도움이 되는 경우도 있을까요?”
- ★ 실천 방법: “오늘 외운 단어 하나를 실제로 써보는 방법을 예로 들어주세요.”

메인 3 · 영어 일기와 오류 수정
> “영어 일기의 틀린 표현은 바로 고쳐줘야 할까요?”
- ★ 판단 기준: “자신 있게 쓰는 아이와 실수를 두려워하는 아이에게 같은 방식으로 피드백하시나요?”
- 실제 사례: “피드백 방식을 바꾸고 아이의 반응이 달라졌던 경험이 있나요?”
- 분기 · ‘일부만 수정’이라면: “무엇을 고치고 무엇은 다음으로 미루나요?”
- 분기 · ‘먼저 칭찬’이라면: “막연한 칭찬 대신 어떤 문장으로 말해주면 좋을까요?”
- ★ 실천 방법: “짧은 일기 한 편을 가져왔을 때 부모의 첫 반응을 실제 말로 들려주세요.”

### 3. 본질·미래 · AI 시대에도 필요한 영어 경험 (줄리 B안과 중복)

1. “AI가 번역과 답변을 도와주는 시대에도 아이가 직접 영어로 해봐야 할 경험은 무엇일까요?” → 꼬리: “그 경험을 집에서 만들어준다면 어떤 활동이 좋을까요?”
2. “아이가 AI와 영어로 대화한다면, 부모는 무엇을 살펴봐야 할까요?” → 꼬리: “아이의 수준과 대화 내용을 확인할 때 구체적으로 무엇을 보시겠어요?”

### 4. 한 문장 마무리

### 예비 질문

- 워밍업·밸런스: “같은 책 여러 번 읽기 vs 새 책 골라 읽기, 오늘 한 가지만 한다면요?” / “영상 같이 보기 vs 책 같이 읽기, 10분이라면요?”
- 심화: “듣기는 잘하는데 말하기는 어려운 아이, 기다리기만 해도 될까요?” / “문법 문제를 잘 푸는 것과 영어로 문장을 만드는 것은 같은 능력일까요?”

공통 꼬리질문: “어떤 아이에게 맞는 방법인가요?” → “잘 맞지 않는 경우는요?” → “실제 경험이 있다면 어떤 변화가 있었나요?” → “집에서는 무엇부터 해볼까요?”
