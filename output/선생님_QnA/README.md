## 문서 규칙 (노션 이관용)

- 제목 계층: `#` 문서 제목 → `##` 파트(A/B) → `###` 섹션 → 질문은 번호 목록
- 질문 아래 들여쓴 `- 의도:` / `- 팔로업:` 은 인터뷰어용 메모 (노션에서 토글로 접어도 됨)
- 표·HTML·각주는 쓰지 않음 (노션 붙여넣기 시 깨짐 방지). README 표는 예외
- 수정 이력은 git 커밋으로 관리, 노션에는 최종본만 반영

## 노션으로 옮기는 법

1. 작업 파일을 열어 전체 복사
2. 노션 빈 페이지에 붙여넣기 → 제목·목록 자동 변환
3. `- 의도:` 줄은 필요하면 선택 후 `Cmd/Ctrl + Opt/Alt + T` 로 토글 처리
