## 문서 규칙 (노션 이관용)

- 제목 계층: `#` 문서 제목 → `##` 파트(A/B) → `###` 섹션 → 질문은 번호 목록
- 대본 파일에는 표를 쓰지 않음 (노션 붙여넣기 시 깨짐 방지). 보고서의 표는 노션에서 단순 표로 변환됨
- 기호: ⭐ 본편 노출 / ★ 필수 꼬리질문 / 🔥 재후킹 / 🎬 편집 포인트 / 🔗 연결 멘트
- 수정 이력은 git 커밋으로 관리, 노션에는 최종본만 반영

## 노션으로 옮기는 법

1. 작업 파일을 열어 전체 복사
2. 노션 빈 페이지에 붙여넣기 → 제목·목록 자동 변환
3. 예비 질문·대안 섹션은 필요하면 토글로 접기
